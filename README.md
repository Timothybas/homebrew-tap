# 🍺 Timothybas Homebrew Tap

Official Homebrew tap for [MacSentinel](https://sentinel.digital).

## Usage

### Install MacSentinel

```bash
brew install --cask timothybas/tap/macsentinel
```

Or add the tap first:

```bash
brew tap timothybas/tap
brew install --cask macsentinel
```

### Update MacSentinel

```bash
brew upgrade --cask macsentinel
```

### Uninstall MacSentinel

```bash
brew uninstall --zap --cask macsentinel
```

## Available Casks

| Cask | Description |
| :--- | :--- |
| [`macsentinel`](Casks/macsentinel.rb) | System cleaner, optimizer, and performance monitor for macOS |
